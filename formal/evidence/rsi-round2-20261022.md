## Production contracts

- History statistics: the latest-started refresh owns publication and failure
  logging. Older completions preserve the accepted totals, character counts and
  latency metrics, including when the latest refresh failed. Cleanup retires
  requests already pending when the page closes.
- Engine status: newer queries and accepted backend events retire obsolete
  query snapshots and failures. Native starts have a separate owner. Loading
  progress and ordinary loading polls preserve the active start; newer starts,
  accepted terminal state and lifecycle/download invalidation retire it.
  A terminal start failure also retires pending status snapshots, preserving
  the error and stopped polling after a delayed loading response.

Public APIs, polling periods, failure/restart thresholds, visual design and
download cancellation behavior are retained. No new dependencies are added.
